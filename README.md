# Waterpearl
A wiki dedicated to music and harp-therapy

Site statique simple (HTML + CSS), hébergé gratuitement avec GitHub Pages.

## Structure

```
Waterpearl/
├── index.html      -> page d'accueil
├── a-propos.html   -> page "À propos"
├── style.css       -> styles communs à toutes les pages
└── images/         -> mettez vos images ici
```

## Voir le site en local

Double-cliquez sur `index.html` pour l'ouvrir dans le navigateur.

## Ajouter une page

1. Copiez `a-propos.html` et renommez la copie (ex. `projet.html`).
2. Changez le titre et le contenu.
3. Ajoutez un lien vers la nouvelle page dans le `<nav>` de **chaque** page.
